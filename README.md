# Projet-Aurora

RPG — JRPG d'exploration (totems & sparkles).

Ce dépôt part de zéro : seul un **socle technique minimal** est présent (écran-titre +
prologue explorable). Aucun système de combat, d'inventaire ou de quête n'est encore
implémenté. Le lore/design reste discuté hors dépôt.

## Stack

- [Vite](https://vitejs.dev/) + TypeScript
- [Phaser 3](https://phaser.io/) (moteur 2D)

## Démarrer

```bash
npm install
npm run dev      # http://localhost:5173
```

## Autres commandes

```bash
npm run typecheck   # vérification TypeScript
npm run build       # build de production (dist/)
npm run preview     # sert le build de production
```
