# Partie 2 — Scène 3D « Sanctuaire »

Nouveau projet Godot. Nom : `Sanctuaire`. Rendu : **Forward+** si ton PC CAO le propose. Sinon **Mobile**. Évite Compatibilité pour cette partie : les lumières et le bloom de la partie HD-2D en ont besoin.

Tu refais la boucle de Ruelles **en volume** : marcher sur un sol, ramasser, être arrêté par des blocs. Le personnage est encore une capsule colorée. Le pixel art arrive dans la partie 3.
